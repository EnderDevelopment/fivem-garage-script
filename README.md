# GarageScript

GarageScript is a FiveM resource that allows players to access and interact with garages in a GTA V FiveM server. It provides a simple and intuitive way for players to access their vehicles stored in different garages. The script includes client-side code to handle player interactions and server-side code to manage vehicle data and garage access.

## Install

1. Download the GarageScript resource from the GitHub repository.
2. Extract the downloaded file into your FiveM server's `resources` directory.
3. Add the following line to your server's `server.cfg` file:
   ```
   ensure GarageScript
   ```

## Use

1. Start your FiveM server.
2. Players can interact with garages by approaching them and pressing the E key.
3. The script will display a list of vehicles available in the garage.
4. Players can select a vehicle to spawn it at the garage location.
